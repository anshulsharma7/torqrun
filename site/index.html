Run your jobs on your machines, orchestrated from one place.

Torqrun schedules and runs Python and shell scripts, workflows and containers on your laptops, servers and cloud VMs through lightweight agents that connect out. No inbound ports, no SSH keys.

How it works

A PostgreSQL-backed control plane, and agents that pull their work.

Start the control plane

make up brings up the API, scheduler, web UI and a bundled agent with Docker Compose.

Connect your machines

Each agent connects out over HTTPS and claims work for the queues it serves. Nothing listens on your servers.

Define and run

Write a job or workflow in the UI or API, schedule it, and watch the output stream live.

Questions

What's free, and what's paid?

The whole orchestration engine is free, with no limits on jobs, runs or agents: schedules, workflows, retries, remote agents, containers, artifacts and metrics. Team adds multiple users and roles, a secrets manager, an audit log and alerts. Enterprise adds SSO, an SLA and compliance help.

Can I self-host the paid plans?

Yes. Team and Enterprise run on your own infrastructure with a license key (checked offline, no phone-home), or we host the control plane for you.

Where does my code run? Where is my data?

Jobs always run on your own agents. With Community, everything else is on your infrastructure too. With Team, we host the control plane (job definitions, run history, logs) and your agents connect to it.

How does it compare to Airflow, Dagster or Rundeck?

Torqrun focuses on running plain scripts reliably across many machines: no SDK to adopt, outbound-only agents, and a fast UI with live logs. It doesn't try to be a data-asset framework.

Is it production-ready?

It's pre-1.0. Every feature is covered by automated tests, a backup and restore drill, load benchmarks and vulnerability scans that run on every change. Start with non-critical workloads and read the production guide.

Can I move from self-hosted to a managed plan later?

Yes. A standard backup and restore moves your history, users and secrets, and your agents keep running.
