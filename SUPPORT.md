# Getting help

| You need | Go to |
|---|---|
| A bug report or a feature idea | [GitHub issues](https://github.com/anshulsharma7/torqrun/issues) (please search first) |
| How to install, configure or operate Torqrun | [docs/](docs/): start with the [README](README.md), then [production.md](docs/operations/production.md) |
| A security vulnerability | **Privately**, see [SECURITY.md](SECURITY.md) |
| Managed hosting, guaranteed support, SSO or a quote | Email **[anshulshrm12@gmail.com](mailto:anshulshrm12@gmail.com)**, see [plans](docs/editions.md) |

Community support is best effort, by the maintainers and other users. If you need response
times you can rely on, the [Team and Enterprise plans](docs/editions.md) include them.
